# Pipeline Kotlin V2 documentation package

This file used to introduce a documentation archive that unpacked a versioned tree under
`docs/`. That tree is no longer shipped or tracked. User-facing documentation now lives in the root
`README.md` (install, DSL, distribution) and `AGENTS.md` (repository workflow policy).

Design records that are still current are stated inline, as KDoc next to the code they
constrain, rather than in a separate document tree.
