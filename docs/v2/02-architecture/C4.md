# C4 Model

## C1 — System Context

```mermaid
flowchart LR
  Dev[Developer] --> PK[Pipeline Kotlin]
  Ops[Platform Engineer] --> PK
  Jenkins[Jenkins] <--> PK
  K8s[Kubernetes] <--> PK
  Cred[Credential Stores] <--> PK
  Art[Artifact Stores] <--> PK
  Obs[Observability] <--> PK
  SCM[SCM] <--> PK
```

Pipeline Kotlin coordina y ejecuta CI/CD; Jenkins es un adapter/control plane posible, no el sistema dueño del runtime.

## C2 — Containers

```mermaid
flowchart TB
  J[plugin: pipeline-jenkins] --> CP[Control Plane]
  CLI[pipeline-cli] --> CP
  CP --> GW[Worker Gateway]
  CP --> ES[(Event Store)]
  ES --> PJ[Projection Service]
  PJ --> GS[(Graph Store)]
  GW <--> W[Worker Runtime]
  K8s[K8s Provisioner] --> W
  W --> AS[(Artifact Store)]
  W --> OT[OTel backend]
```

## C3 — Worker Runtime

```mermaid
flowchart LR
  SRC[Pipeline Source] --> SE[Scripting Adapter]
  SE --> RT[Durable Runtime]
  RT --> SR[Step Registry]
  SR --> EX[Executors/Capabilities]
  RT --> J[(Local Journal)]
  J --> TX[Protocol Session]
  EX --> WS[Workspace]
  EX --> AR[Artifact Publisher]
  EX --> CR[Credential Projection]
```

## C3 — Jenkins Adapter

```mermaid
flowchart LR
  FD[KotlinPipelineDefinition] --> FE[KotlinPipelineExecution]
  FE --> RC[Run Client]
  EV[Worker/Run Events] --> RED[FlowGraph Reducer]
  RED --> FN[FlowNode Storage]
  RED --> LOG[Pipeline Logs]
  FE --> FN
```

`FlowExecution` no contiene el runtime Kotlin ni una continuation; conserva run identity, heads/projection state, last sequence y comandos de control.
