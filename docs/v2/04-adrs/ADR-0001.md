# ADR-0001: Motor independiente; Jenkins como adapter

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

El objetivo de V2 es reducir la carga del controller y permitir CLI/SaaS futuros. Si el core depende de Jenkins, la distribución y el testing quedan condicionados por `workflow-*`, Remoting y lifecycle Jenkins.

## Decision

Pipeline Kotlin será un motor independiente. Jenkins se integra mediante `pipeline-jenkins-plugin`, que traduce Job/FlowDefinition/FlowExecution a comandos y proyecta eventos a FlowNodes.

## Consequences

Permite reutilizar runtime fuera de Jenkins y delimita responsabilidades. Aumenta el trabajo inicial porque hay que definir ports/protocolos propios y un adapter Jenkins explícito.

## Guardrails / evidence

Fitness test: `pipeline-domain` y `pipeline-application` no pueden depender de paquetes `hudson.*`, `jenkins.*` u `org.jenkinsci.*`.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
