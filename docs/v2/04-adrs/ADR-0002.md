# ADR-0002: Kotlin Custom Scripting como frontend principal

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Se desea una experiencia `.pipeline.kts` similar a `Jenkinsfile`/`build.gradle.kts`. Kotlin Custom Scripting sigue etiquetado Experimental, pero la tecnología se usa de forma productiva y Gradle ha invertido en el Scripting Host para Kotlin DSL/K2.

## Decision

Usar Kotlin Custom Scripting para `.pipeline.kts`, encapsulado en `pipeline-scripting-kotlin24`. Fijar Kotlin por release, no exponer `kotlin.script.experimental.*` en APIs propias y mantener fallback/compiler SPI.

## Consequences

Se acepta riesgo de source/binary API changes del host a cambio de una UX excelente. El coste queda acotado a un adapter versionado y compatibility corpus.

## Guardrails / evidence

Sólo módulos `pipeline-scripting-kotlin*` pueden importar `kotlin.script.experimental`. CI prueba stable+RC+EAP.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
