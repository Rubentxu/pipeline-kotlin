# ADR-0003: Context parameters para capabilities de Steps

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

V1 usa context/service locator amplios. Kotlin 2.4 estabiliza context parameters y permite expresar dependencias implícitas sin convertirlas en estado global.

## Decision

Los Steps declaran capabilities mínimas con context parameters: `context(fs: Workspace)`, `context(process: ProcessExecutor)`, etc.

## Consequences

Mejora DIP, testing y legibilidad de dependencies. Requiere disciplina para evitar un `RuntimeContext` gigante que recree Service Locator.

## Guardrails / evidence

Lint/architecture test limita tipos contextuales agregados; Step descriptors reflejan required capabilities.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
