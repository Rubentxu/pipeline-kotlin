# ADR-0004: KSP como codegen principal; FIR/IR opcional

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

El compiler plugin actual ha sufrido errores IR y las APIs de compiler plugins son más sensibles a upgrades. La mayoría de necesidades son metadata/codegen, no transformación semántica profunda.

## Decision

Usar KSP para descriptors, façades, schemas, serializers metadata, docs y LSP indexes. FIR/IR sólo para diagnostics/instrumentación imposible de obtener de otro modo.

## Consequences

Reduce dependencia de internals K2 y facilita upgrades. Puede requerir pequeñas diferencias respecto a una DSL mágicamente transformada.

## Guardrails / evidence

Happy path debe compilar con compiler plugin desactivado. Existe test dedicado `no-compiler-plugin`.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
