# ADR-0005: Jenkins Familiarity Contract

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

La adopción depende de que el developer reconozca Pipeline y plugins populares, pero no se desea compatibilidad binaria ni heredar APIs dinámicas inseguras.

## Decision

Definir niveles F0 Naming, F1 Surface, F2 Behavioral, F3 Migration y metadata `@JenkinsSurface` por Step.

## Consequences

Hace mensurable la familiaridad y permite desviaciones tipadas. Obliga a mantener una compatibility matrix por Step.

## Guardrails / evidence

Todo Step que reclame F2/F3 debe tener UAT/golden examples comparando casos documentados.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
