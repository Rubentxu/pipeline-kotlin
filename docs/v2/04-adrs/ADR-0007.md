# ADR-0007: Event Log como fuente de verdad

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Estado distribuido, recovery, auditoría y grafos necesitan una historia común y verificable.

## Decision

Todos los cambios de estado relevantes se expresan como eventos append-only versionados. Reducers/projections reconstruyen estado.

## Consequences

Simplifica audit/recovery/fork; requiere schema discipline, compactación/snapshots y storage operativo.

## Guardrails / evidence

Projection rebuild tests deben producir el mismo estado desde cero y desde snapshot+tail.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
