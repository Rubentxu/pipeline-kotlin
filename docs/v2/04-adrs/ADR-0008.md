# ADR-0008: Graph-native mediante proyecciones

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

El dominio CI/CD es relacional: commit→run→step→worker→artifact→deployment. Una vista de logs/tablas pierde causalidad y provenance.

## Decision

Materializar Plan, Execution y Provenance Graph desde eventos. Graph store no es source of truth ni requisito del hot path.

## Consequences

Habilita consultas, UI, AI, fork/diff y supply chain. Añade projectors y eventual consistency.

## Guardrails / evidence

Eliminar graph store y reconstruirlo debe ser soportado/testeado.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
