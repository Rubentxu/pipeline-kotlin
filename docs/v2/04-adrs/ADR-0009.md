# ADR-0009: Protobuf para contratos wire

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Java serialization/Any/Map no son apropiados para un runtime distribuido versionable y seguro.

## Decision

Todos los mensajes worker/control-plane usan Protobuf con schemas versionados y mappings explícitos domain↔wire.

## Consequences

Mejora interoperabilidad, compatibilidad y seguridad. Introduce schema governance/generation.

## Guardrails / evidence

Golden binary compatibility tests; prohibido serializar clases Java/Kotlin arbitrarias.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
