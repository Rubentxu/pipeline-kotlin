# ADR-0010: WebSocket MVP y gRPC Gateway como target

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Jenkins puede exponer HTTPS/WebSocket fácilmente; gRPC directo a miles de workers desde controller añadiría sockets/Netty y carga al proceso que intentamos descargar.

## Decision

MVP: Protobuf sobre binary WebSocket. Escala objetivo: Worker Gateway externo con gRPC bidireccional/mTLS; Jenkins mantiene pocas conexiones lógicas.

## Consequences

Permite entrega incremental sin comprometer arquitectura de escala. Requiere Transport port y dos adapters potenciales.

## Guardrails / evidence

Protocol conformance suite debe ejecutarse contra ambos transports.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
