# ADR-0011: At-least-once, ACK/replay, leases y fencing

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Redes fallan, mensajes se duplican y un worker puede reaparecer tras ser reemplazado.

## Decision

Adoptar at-least-once; eventId dedupe; sequence/ACK; local outbox journal; lease temporal y fencing token monotónico.

## Consequences

Evita promesas imposibles de exactly-once y split-brain. Requiere reducers idempotentes.

## Guardrails / evidence

Chaos UAT con partitions/reconnects verifica rechazo de token antiguo y no duplica transitions.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
