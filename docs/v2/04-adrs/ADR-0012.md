# ADR-0012: Workers V2 no son Jenkins Node/Computer por defecto

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Modelar workers como `Node/Computer` obligaría a `Launcher/FilePath/VirtualChannel` y reintroduciría Remoting en el core.

## Decision

Crear Worker/Pool/Capabilities/Scheduler/Lease propios. Jenkins sigue siendo adapter de jobs/queue/UI.

## Consequences

Mayor libertad y workers no-Jenkins; plugins Jenkins arbitrarios dejan de ser reutilizables, decisión aceptada por producto.

## Guardrails / evidence

Ningún módulo worker/runtime depende de Jenkins Remoting.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
