# ADR-0013: Kubernetes como WorkerProvisioner

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Kubernetes es el caso principal de workers efímeros, pero el motor debe funcionar local/static y poder incorporar otros schedulers.

## Decision

`KubernetesWorkerProvisioner` implementa un port genérico. DSL Kubernetes mantiene conceptos familiares `inheritFrom`, `yaml`, `defaultContainer`, `retries`.

## Consequences

Buen acoplamiento con K8s sin vendor lock-in. Requiere `WorkerTemplate` propio y bridge opcional a PodTemplate Jenkins.

## Guardrails / evidence

Core tests usan fake provisioner; K8s integration tests sólo en adapter.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
