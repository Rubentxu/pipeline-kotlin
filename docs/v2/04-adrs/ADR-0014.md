# ADR-0014: Credential provider + lease + projection

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Credentials pueden venir de Jenkins, Kubernetes, Vault, cloud stores u OIDC. Copiar secret bytes al controller/gateway aumenta exposición.

## Decision

Modelar `CredentialRef -> CredentialLease -> CredentialProjection`; preferir workload identity/CSI. Providers detrás de port.

## Consequences

Reduce acoplamiento y exposición. Añade lifecycle/scoping/revocation que debe implementarse cuidadosamente.

## Guardrails / evidence

Secret scanning de event/journal/log fixtures es blocking; providers pasan contract suite.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
