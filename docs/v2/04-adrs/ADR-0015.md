# ADR-0015: Plugins propios verificables y distribuibles

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

No se necesita compatibilidad binaria Jenkins; sí ecosistema extensible, reproducible y familiar.

## Decision

Plugin API propia con descriptors generados, digests, lockfile y objetivo de distribución OCI con SBOM/provenance/signature metadata.

## Consequences

Permite supply-chain y caching. Requiere registry/catalog y compatibility policy.

## Guardrails / evidence

Plugin sin descriptor/effects/replay/schema no puede publicarse como stable.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
