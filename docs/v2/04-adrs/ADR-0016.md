# ADR-0016: Sandbox OS/container, no Java Security Manager

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Security Manager ya no es una base viable para aislar scripts modernos. ClassLoader no es una sandbox.

## Decision

Aislamiento mediante container/OS: non-root, seccomp, cgroups, filesystem/network policies; hardening opcional gVisor/Kata/microVM.

## Consequences

Alinea seguridad con workers efímeros. Incrementa requisitos operativos y profiles de ejecución.

## Guardrails / evidence

Security UAT intenta filesystem/network/privilege escapes según profile.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
