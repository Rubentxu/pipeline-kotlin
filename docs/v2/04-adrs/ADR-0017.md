# ADR-0017: Artifacts direct-to-store y provenance nativa

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Proxyar artifacts grandes por controller penaliza escalabilidad y pierde contexto de supply-chain.

## Decision

Worker sube directo mediante scoped capability/presigned URL. Publica sólo metadata/digest y relations de provenance.

## Consequences

Reduce carga controller y habilita trazabilidad. Necesita ArtifactStore ports, retries e integrity verification.

## Guardrails / evidence

Digest verificado antes de ArtifactPublished; controller nunca requiere body para registrar artifact.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
