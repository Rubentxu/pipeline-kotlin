# ADR-0019: Matriz certificada Kotlin/runtime/plugin API

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

APIs scripting/compiler pueden cambiar. Permitir versiones arbitrarias trasladaría riesgo al usuario.

## Decision

Cada runtime certifica Kotlin/JDK/DSL API/Plugin API/Protocol. Adapters scripting se versionan por línea Kotlin.

## Consequences

Upgrades son deliberados y testeables; se sacrifica flexibilidad arbitraria.

## Guardrails / evidence

Compatibility corpus stable es blocking; RC/EAP nightly early-warning.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
