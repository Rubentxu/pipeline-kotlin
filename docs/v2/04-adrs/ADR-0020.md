# ADR-0020: BTA como adapter futuro, no dependencia V2.0

- **Status:** Accepted for V2 design
- **Date:** 2026-08-21
- **Decision owners:** Pipeline Kotlin maintainers

## Context

Build Tools API es estratégica y ya se usa en KGP/Maven, pero aún es Experimental/no está planteada como integración pública general para terceros.

## Decision

Mantener `PipelineCompiler` port y un spike BTA. Adoptar sólo cuando el contrato/beneficio supere al adapter scripting existente.

## Consequences

Preserva una vía futura hacia incremental compilation/daemon sin bloquear V2.0.

## Guardrails / evidence

SPIKE-007 mide viabilidad, API churn, cache/incremental y aislamiento.

## Revisit when

Revisar si cambia una premisa externa fundamental, aparece evidencia de producción que invalida la decisión o una alternativa reduce materialmente complejidad/riesgo sin romper los objetivos de producto.
