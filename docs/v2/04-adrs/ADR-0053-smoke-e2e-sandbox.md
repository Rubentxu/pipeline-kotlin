# ADR-0053 — ML-R8 L7 smoke E2E sandbox (hybrid runner-on-host + devbox-pinned JDK + Just lifecycle + per-run SANDBOX_RUN_ID)

> **Cycle:** `p-733fb505b5a6bd2d/ml-r8-smoke-e2e-sandbox`
> **Phase:** design → tasks (Tier L7 / A-full)
> **Authority:** `docs/v2/05-roadmap/ROADMAP.md:240-244` + `ADR-0046` §ML/L7 + `ADR-0048-sandbox-profile-local` + `ADR-0049-credentials-local`
> **Base SHA:** `acdeea4` (= v0.21.0 = ML-R7 closure = HEAD)
> **Spec set:** 7 files (5 NEW + 2 DELTA) under `cycle-artifacts/p-733fb505b5a6bd2d/ml-r8-smoke-e2e-sandbox/specs/`

## Context

ADR-0046 §ML/L7 closes the ML milestone with a **smoke E2E harness** over real famous OSS repos. Gate is `UAT-LOCAL-006` per `docs/v2/07-uat/UAT_SCENARIOS.md:148-149`. Today every prior UAT-LOCAL harness (001..009) is synthetic (in-process mocks, `file://` bare repos, hand-crafted artifacts). L7 closes the loop with **real wrapper-driven builds** against 4 pinned public OSS repos (`remkop/picocli` + `cbeust/jcommander` + `vavr-io/vavr` + `fusesource/jansi`).

ML-R8 ships the **hybrid sandbox (Approach D)**: runner-on-host (parity with UAT-LOCAL-001..009) + devbox-pinned JDK 21 toolchain (matches `v2/**/build.gradle.kts` `jvmToolchain(21)` — verified across 18 modules) + Just lifecycle + trap-clean Bash + per-run `SANDBOX_RUN_ID` scoping + persistent Gradle cache.

Zero new V2 production code — the harness CONSUMES L5 (`GitCheckoutExecutor`) + L6 (`writeFile`/`sh`/`archiveArtifacts`) step surface unchanged.

## Decision

### D1 — Sandbox architecture: Hybrid (Approach D)

Runner-on-host + devbox-pinned `jdk@21` + Just lifecycle + trap-clean Bash + per-run `SANDBOX_RUN_ID`.

**Rationale (vs. alternatives):**
- (a) **Plain host (Approach A)** — REJECTED: JDK version drift (host has Temurin-24; V2 targets 21 per `v2/**/build.gradle.kts` `jvmToolchain(21)`); no trap-clean; no per-run scoping.
- (b) **Devbox shell only (Approach B)** — REJECTED: no Just interface discoverability + no lifecycle discipline.
- (c) **Full-Podman (Approach C)** — REJECTED: adds 2 container layers for zero isolation benefit at L7 fidelity; runner is already process-level isolated via `--control-root` + per-stage workspace.

**Chosen**: Approach D (Hybrid). Consistency with every prior UAT-LOCAL harness; pins JDK 21 across machines; trap-clean guarantees zero orphan processes; per-run `SANDBOX_RUN_ID` enables parallel smokes; Gradle cache persists across runs. One upgrade path to full Podman via `just sandbox-up` overlay (L7.2).

### D2 — `justfile` shape: 6 recipes in 2 groups

```
[group('sandbox')]: doctor, bootstrap, smoke, smoke-clean
[group('test')]:    uat, uat-local-010
```

**Rationale:** Skill §23 mandates Just as canonical entry point + groups for discoverability (`just --list`). NO `set dotenv-load`: env lives in `devbox.json` `env` block + script `export`. Trap semantics MUST live in Bash because Just CANNOT express `trap`-on-error.

### D3 — `devbox.json` content

```json
{
  "packages": ["jdk@21", "git", "curl", "jq"],
  "env": {
    "JAVA_HOME": "{devbox.jdk}/lib/openjdk-21",
    "GRADLE_USER_HOME": "$XDG_CACHE_HOME/gradle",
    "MAVEN_OPTS": "-Dmaven.repo.local=$XDG_CACHE_HOME/m2"
  },
  "shell": { "init_hook": null }
}
```

**Rationale:** `jdk@21` (NOT 24) because `v2/**/build.gradle.kts` declares `jvmToolchain(21)` per module — verified across 18 modules. NO `gradle` package because subject repos' `gradlew`/`mvnw` wrappers pin their own Gradle distribution. `GRADLE_USER_HOME`/`MAVEN_OPTS` exported under `$XDG_CACHE_HOME` for persistent cache.

### D4 — `devbox.lock`: version-controlled, generated by `devbox install`

**Rationale:** Skill §7 mandates version-control; reproducibility across machines + future CI runners.

### D5 — Bash lifecycle: 6 scripts under `scripts/sandbox/`

`common.sh` (log/die/sandbox_run_id/require_cmd) + `run-smoke.sh` + `run-uat.sh` + `collect-logs.sh` + `cleanup.sh` + `wait-http.sh` (no-op stub).

Every script: `#!/usr/bin/env bash` + `set -Eeuo pipefail` + `trap 'cleanup $? $LINENO' EXIT INT TERM`.

**Rationale:** Skill §24 + §25 mandate trap prologue; §47 mandates Bash lifecycle (NOT Just dependencies) because Just CANNOT express `trap`. `wait-http.sh` kept for skill-pattern parity (reserved for L7.2 Podman overlay).

### D6 — `run-smoke.sh` body shape

```bash
trap 'cleanup $? $LINENO' EXIT INT TERM
export SANDBOX_RUN_ID=$(date -u +%Y%m%dT%H%M%S)-$$-$RANDOM
export V2_SMOKE_E2E_OK=true
mkdir -p artifacts/smoke/$SANDBOX_RUN_ID
timeout 600 devbox run -- ./gradlew -p v2 :pipeline-application:test --tests 'UatLocal010*'
# on rc != 0: collect-logs.sh BEFORE cleanup.sh
```

**Rationale:** `timeout 600` wrapper per AGENTS.md rule 4 (silent hangs are defects of the harness, not code under test). `collect-logs.sh` BEFORE cleanup per skill §25 + §9 (diagnostics retention is the contract). `V2_SMOKE_E2E_OK=true` is the sole documented setter of the D7 gate.

### D7 — `UatLocal010SmokeE2ESandboxTest` class

```kotlin
@Timeout(600)                                    // AGENTS.md rule 7
class UatLocal010SmokeE2ESandboxTest {
    @AfterEach fun teardown() {
        destroyForcibly(); pgrep -P <self> SIGKILL  // AGENTS.md rule 8
    }
    assumeLinux()                                 // UAT-LOCAL-005/009 precedent
    @EnabledIfEnvironmentVariable(V2_SMOKE_E2E_OK) // network-bound opt-in
    // runPipeline verbatim from UAT-LOCAL-009:74-111
    // @TempDir per scenario
    // NO maxParallelForks
}
```

**Rationale:** Class-level `@Timeout` ensures hung test fails in seconds (rule 7). `pgrep -P <self>` kills `setsid` children (rule 8). `V2_SMOKE_E2E_OK` opt-in prevents offline dev environments from FAIL (parity with `V2_NETWORK_OK`).

### D8 — `runPipeline` helper: PIPE + JsonEventLog.decode(stdout)

```kotlin
ProcessBuilder(args)
    .directory(tempDir.toFile())
    .redirectOutput(ProcessBuilder.Redirect.PIPE)
    .redirectError(ProcessBuilder.Redirect.PIPE)
    .start()
// NOT inheritIO(): SC-010-12 requires parsing emitted events from stdout
val events = JsonEventLog.decode(stdout)
```

**Rationale:** The proposal §A4 shows `inheritIO()` (illustrative shorthand). The actual precedent (`UatLocal009TopStepsTest.kt:93-110`) uses `PIPE` + `JsonEventLog.decode(stdout)`. SC-010-12 (canary round-gate) requires parsing the runner's emitted events from stdout.

## Threat Model

| Surface | Description | Mitigation |
|---|---|---|
| JDK drift | Host Temurin-24 vs V2 target 21 | devbox `jdk@21` pin; `just doctor` checks |
| Subject-repo rotation | Pinned SHA no longer accessible or changed | 4 repos selected for stability; SHAs verified 2026-08-29 |
| Gradle daemon leak | Daemon survives test, causes OOM or port conflict | `cleanup.sh` pgrep -P SIGKILL; `setsid` children killed |
| Network failure | Offline dev env; Git/Maven/Gradle fetch fails | `@EnabledIfEnvironmentVariable(V2_SMOKE_E2E_OK)` disables online scenarios; offline canary (SC-010-08) |
| V2 prime-directive firewall | V2 production modules touched | Zero V2 production code; harness only in test source set |
| Parallel-cache collision | Two `just smoke` runs share `GRADLE_USER_HOME` | Per-run `SANDBOX_RUN_ID`; disjoint `artifacts/smoke/<id>/` |
| CI misalignment | Local success ≠ CI success | devbox.lock version-controlled; `timeout 600` wrapper; JDK 21 pin |
| Wrapper-output redaction | `__artefact_canary__` leaks to events/journal/logs | `RedactingEventSink` wraps all emission at `Main.kt:179,189,201`; canary registered at `Main.kt:173` |

## Consequences

### Positive

- Closes the ML milestone with a real-E2E smoke gate over famous OSS repos
- Hybrid approach maintains parity with every prior UAT-LOCAL harness (001..009)
- devbox `jdk@21` pin ensures toolchain alignment across machines
- Trap-clean Bash guarantees zero orphan processes across all exit paths
- Per-run `SANDBOX_RUN_ID` enables parallel smoke runs without cache collision
- Persistent Gradle cache reduces wall-clock on warm re-runs
- Zero V2 production code changes — additive only

### Negative

- `devbox install` requires nix — first-run setup is heavier than `pip install`
- JDK 21 pin must be manually kept in sync if V2 bumps to 22+ (Value connascence pair)
- Online scenarios gated by `V2_SMOKE_E2E_OK` — offline dev environments see 6 DISABLED tests (correct but non-obvious)
- L7.1/L7.2/L7.3 deferred: private-repo credentials, Podman isolation, CI integration

## Appendix: §Subject Pinning Protocol (HARDENED, applied 2026-08-29)

### The Problem

Design §D9 originally claimed: "SHAs verified via `git ls-remote <url> HEAD` on 2026-08-29;
pinning by SHA = immutable." This only confirmed the SHA exists as a branch tip — it did NOT
confirm the wrapper file (`mvnw`/`gradlew`) exists at that SHA.

Evidence: jcommander@e9599fe has no `./mvnw` (git log --all -- mvnw → empty).
fusesource/jansi@c10d43f no longer exists on upstream (force-pushed history).

### HARDENED 2-Gate Protocol

Any subject re-pin MUST pass BOTH gates before being committed:

**Gate A — Reachability**: `git ls-remote <url>` shows the repo is accessible. The SHA
must be reachable via `git fetch <sha>` or `git clone + git checkout <sha>`.

**Gate B — Wrapper Presence**: Tree probe at the pinned SHA shows the wrapper file
(`mvnw`/`gradlew`) is present, via:
- **Option 1 (preferred)**: GitHub API `GET /repos/:owner/:repo/git/trees/<sha>?recursive=1`
  filtered to `mvnw`/`gradlew` — unauthenticated, rate-limit aware.
  ```bash
  curl -s "https://api.github.com/repos/google/guava/git/trees/d5cc108?recursive=1" \
    | python3 -c "import sys,json; items=[i['path'] for i in json.load(sys.stdin).get('tree',[])]; print('mvnw' in items)"
  ```
- **Option 2**: Shallow clone + `test -f mvnw` / `test -f gradlew`
  ```bash
  git clone --depth 1 https://github.com/owner/repo.git /tmp/probe \
    && cd /tmp/probe \
    && git fetch --depth 1 origin <sha> \
    && git checkout FETCH_HEAD \
    && test -f mvnw && echo "HAS mvnw" || echo "NO mvnw"
  ```

**Cycle-level invariant**: Any re-pin that fails either gate MUST NOT be committed.
Probe evidence (command + output digest) MUST be recorded in the test class comments
at the constant declaration.

### Execution Order

Online scenarios and offline canaries have different timing semantics:

1. **Online first**: `V2_SMOKE_E2E_OK=true` → `UatLocal010SmokeE2ESandboxTest`
   (12 scenarios: 7 online + 5 offline/crosscut, ~12 min wall-clock)
2. **Offline second**: `V2_SMOKE_E2E_OFFLINE_OK=true` →
   `UatLocal010SmokeE2ESandboxOfflineTest` (2 scenarios: SC-010-08 offline canary +
   SC-010-12 artefact canary, ~2 min wall-clock after warm cache)

Offline canaries REQUIRE the online class to run FIRST to warm the Gradle/Maven caches.
Running offline class standalone will produce different (cache-cold) timings.
