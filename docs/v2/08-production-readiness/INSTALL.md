# Installation

Copy the package contents into the repository root.

The only repository path introduced by this package is:

`docs/v2/08-production-readiness/`

No existing file is overwritten by the package itself.

Recommended first commit:

`docs(production-readiness): add audit-driven RP-5 closure action plan`

After incorporation, execution begins with `EXECUTIVE_SUMMARY.md` and `backlog/IMPLEMENTATION_BACKLOG.md`.
